# 兼容性和证据范围

| 项目 | 当前范围 |
| --- | --- |
| 在线运行平台 | Windows x64，合法 Steam App730 普通观众上下文 |
| 原生桥 / 解析进程 | ABI 3 / 有序 IPC 3 |
| CLI host 白名单 | 14191、14192 |
| 真实接入记录 | CS2 build 10955、host 14192、Patch 1.41.9.2；两个授权来源 |
| 固定原生研究对象 | host 14191 / build 10924；以模块摘要绑定规则 |
| 解析器 | cs2parser 2.7.2，固定上游提交加本仓库补丁 |
| 换图契约 | 新 GOTV 地址、新来源 UUID/代际 |

真实验证覆盖持续收流、开局/冻结期等源实际发出的生命周期事件、控制器身份、比赛结束和正常清理。旧样本的应用通道可以确定性重放。详细历史见[实测记录](../archive/docs/LIVE-2026-10-24.md)。本仓库不附带真实比赛原始材料。

控制器 Steam 身份由当前世界 controller 与 userinfo 一致性证明；pawn 需另外通过完整 serial 等验证。userinfo 空值清除旧身份；缺失不等于选手真实退服。不能复用旧身份填空。

两路事件接收差约 120 秒是特定源的观测，热身过渡存在变化，不是固定偏移保证或 OBS 逐帧校准。部分源不发送另一源具有的事件，不合成 round_start 等补齐覆盖。

一次晚加入创建序列准入失败的根因仍未证明；后续重试成功不等于根因修复。未知版本、任意源、同连接换图、任意长时间稳定运行均未自动获得验收。

进程重试由消费者拥有；本程序单次运行拥有一个来源，不自动重连。消费应用的界面和提示产品独立于本体。

上游普通观众能力标记 ordinaryViewerProtocol=2 与有序 IPC 3 是不同字段，不做全局数字替换。

最低外部运行时：Node.js 24.0.0，具备WebAssembly、ReadableStream和structuredClone；小版本不作允许列表。Windows包需要Windows x64 Node；离线源码工具可在对应平台验证。
