# 离线性能检查

2026-10-25，Windows x64、Node 24.21.0，对同一份本机授权捕获进行顺序 A/B 回放。输入为 host14192 的14431帧、约113.5秒来源数据，输出466条公共记录。原始捕获、选手资料和CPU profile只留本机。

使用Node内置Inspector进行1ms间隔CPU采样；下表为单轮观察，不是跨硬件性能保证。回放包括Python驱动、进程管道和完整实体解码，不能把投影局部成本当作整链路成本。

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 字段读取累计采样 | 124.6ms | 20.5ms |
| 事件投影累计采样 | 150.8ms | 66.0ms |
| worker非idle累计采样 | 12190ms | 12602ms |
| 整体回放墙钟时间 | 42.875s | 43.031s |

整体耗时没有可确认改善，worker总采样时间也没有下降；收益是减少投影查找中的无关字段复制与冻结。字段名过滤发生在防御性复制之前，所有匹配项仍被遍历，重名字段继续判为不确定，返回值仍保留防御性复制。没有添加跨事件、快照或世界缓存。

GameRules遍历及类查询在基线中累计约9ms；当前没有证据支持为它增加缓存和失效机制，保留原实现。未知实体编码、身份缺失与解析恢复规则均不因性能检查而放宽。

同一回放的466条记录所有JSON字段一致。组件回归另验证按名称读取与完整遍历过滤结果一致、缺失名称、二进制值的防御性复制及重名身份字段。完整通道回归、构建与制品验证按[验证说明](verification.md)分别记录；离线回放不证明新的GOTV握手或来源结束行为。
