# 离线性能检查

## 方法

2026-10-25，在 Windows x64、Node 24.21.0 上顺序回放同一份授权通道，使用 Node Inspector Profiler 以 1 ms 间隔采样。输入为 host 14192 的 14431 帧、约 113.5 秒来源数据，输出 466 条公共记录。原始捕获与 CPU profile 保存在本机。

回放包含 Python 驱动、进程管道和完整实体解码。采样结果对应表中输入与环境，实际制播负载另按运行组合测量。

## 测量结果

| 项目 | 基线 | 字段读取优化后 |
| --- | --- | --- |
| 字段读取累计采样 | 124.6 ms | 20.5 ms |
| 事件投影累计采样 | 150.8 ms | 66.0 ms |
| worker 活动累计采样 | 12190 ms | 12602 ms |
| 整体回放墙钟时间 | 42.875 s | 43.031 s |

## 采用方案

字段查找先按名称筛选，再复制、冻结匹配值。所有同名记录继续参与判定，返回值保留防御性复制；实体状态由当前快照持有。

收益集中在投影局部读取成本，整体回放耗时约 43 秒。GameRules 遍历与类查询的基线累计约 9 ms，继续采用逐事件读取当前快照的方式。

两轮输出的 466 条记录逐字段一致。组件检查覆盖名称过滤、缺失名称、二进制值复制和重名身份，完整通道回归按[验证说明](verification.md)记录。
