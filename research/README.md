# 研究知识与证据

这里保留可复用技术依据，研究数据不作为默认验证的输出目录。

- [知识库](knowledge/README.md)：88 条结论、80 个来源及摘要校验。
- data/：固定构建原生对照、合成向量、模块摘要及机器证据。
- evidence/：早期解析、编译和回归结果，按原日期与范围阅读。
- references/：参考项目来源、模块覆盖及复用边界。
- tools/：可选研究复现，包含本机固定模块模拟；不进入便携运行依赖。

当前运行支持见[兼容性](../docs/compatibility.md)；阶段进度与旧设计已移入[归档](../archive/README.md)。

## 复现环境

默认仓库验证只读取保留向量，见[验证说明](../docs/verification.md)。原生函数模拟另需 Python 3.12、capstone 5.0.6、unicorn 2.1.4，以及自行合法取得且摘要匹配的固定游戏模块。
研究工具保留历史工作区输入约定，见[固定类型与工作区配方](tools/TYPE-PROFILE-REPRODUCTION.md)。它们不是开箱即用的客户端命令。

为保持模型与旧原生证据的可追溯性，本轮不批量改写这些历史模拟器的硬编码布局；新研究运行在独立临时工作区，先按配方放置输入，原始模块和输出不入库。
七个现行组件测试已移至 tests/parser，只读 data/，结果写 work/。两个依赖旧比较源码的量化比较脚本已归档。

结构与摘要校验：`python research/knowledge/validate.py .`。它验证索引和字节身份，不证明结论的语义正确或在线互操作。
