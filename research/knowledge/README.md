# CS2 本地技术知识库

本库面向 DAK、demo-format、Mizar 及后续本地游戏工具，按技术主题组织，不以单一产品需求作为分类边界。只收已核实结论；证据、验证方法、固定版本与适用范围共同组成结论。

## 阅读与复用

- [完整主题索引](reference.md)：按主题阅读结论和证据。
- [结构化结论](facts.json)：稳定条目 ID、技术域、结论、方法、模块、来源及复用边界。
- [复用指南](reuse.md)：选择正确的数据域与证据层级。
- validate.py：校验结构、证据文件存在性与摘要；这些检查不替代语义研究。

## 研究对象

固定 Windows x64 构建14191/10924，二进制 depot2347771 / manifest8766757721818354077。六个模块的 SHA-256 见 [清单](../data/module-manifest.json)。资源兼容配置另行固定版本。地址、结构布局与注册结果不得脱离模块摘要复用。

## 证据层级

- native-static：固定模块控制流、注册表或调用关系的静态核对。
- native-isolated：固定模块指令在隔离内存中的执行对照，只覆盖所述输入与路径。
- fixture-observation：指定样本或合成夹具的直接观察。
- 实时接入、账号认证、Windows 启动和真实比赛验收是独立结果。本库不以静态或离线测试代替它们。
