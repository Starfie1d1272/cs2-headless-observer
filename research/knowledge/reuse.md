# 复用指南

## 按数据域选择结论

1. Schema 与类型：从 TYPE 条目开始，分别保存名称、版本、类别、维数和 encoder，按 wire 编码消费字段。
2. Demo 解析：根据录像构建与协议分支选择字段路径、标量、容器和表结构规则，保留各兼容配置的版本身份。
3. 赛事统计：组合 ENTITY、IDENTITY、EVENT 和 TABLE 结论，通过对应版本、当前世界及身份一致性关联槽位、userid、实体 handle 与 Steam64。
4. 镜头与几何：COORD、ANGLE、ORIGIN 描述网络属性；渲染坐标还需对应的父变换、插值和动画依据。
5. 本地诊断：记录版本摘要、来源角色、通道和世界代际、消息顺序、有效快照 tick 及网络时钟，分别保留各时间域。
6. 传输与初始化：NET、AUTH、SIGNON、WORLD 各自对应一层证据。Steam 认证与可靠传输使用官方接口，应用帧、表、实体提交和订阅由相应解析层管理。

## 证据与实现策略

原生结论说明固定构建的处理路径。队列预算、严格身份验证、错误隔离和重试属于观察器的实现策略，各自记录选择与边界。结构校验、离线处理和在线接入分别提供对应层级的证据。

## 更新

知识条目保留稳定 ID。修正结论时同步版本范围、直接来源与复现方法，新构建使用独立版本条目，历史地址与摘要继续可追溯。
